# 今日头条排版规范

## 标题规范
- **字数**：22-30 字（平台限制 2-30 字，但 22-30 是爆款区间）
- **结构**：前半句设悬念/抛冲突 → 逗号 → 后半句放大招
- **必含元素**：具体人名 + 数字/时间 + 情绪词/反差词
- **六种爆款公式**：
  1. 反差反转："56岁身患不死癌症的张嘉益，再破天花板，让内娱刮目相看"
  2. 悬念揭秘："看了陈雨昂近照，才懂陈凯歌陈红，为何只把陈飞宇送进娱乐圈"
  3. 反问引思："赚再多钱有什么用？歌后张靓颖的遭遇，给娱乐圈提了个醒"
  4. 数字冲突："2026男明星咖位大洗牌：欧豪难进前5，肖战第2，第1没争议"
  5. 事件爆点："《家业》播出2天，难堪一幕发生，杨紫和赵丽颖栽进同一个坑"
  6. 现象评价："过气明星扎堆找退路，风波升级反惹群嘲，意外牵连半个娱乐圈"
- **参考对标**：写标题前搜 `references/accounts.md` 中账号同主题文章，学结构不抄文案

## 正文排版
- **加粗规则**：以下内容必须加粗
  - 每段的中心句
  - 反转点、关键结论
  - 金句
  - 数字和关键人名作品名
- **段落**：每段不超过4行，大量使用短句。
- **分隔**：重要转折前用 `---` 或一个小标题。
- **图片标记**：在 JSON 数据中使用 `"type": "image"` 节点，`query` 字段填写百度图片搜索关键词，`description` 字段填写图片占位说明。自动生成时每 200-300 字插入一张，居中嵌入 .docx，不附加说明文字。
