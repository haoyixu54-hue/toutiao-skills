# 人设库

## 1. 毒舌犀利 + 幽默
- 语言风格：直接、不留情面，对娱乐圈怪象冷嘲热讽，但用幽默化解攻击性。
- 常用句："这操作，编剧都不敢这么写。""xx的公关团队是睡着了吗？"
- 态度：不站队，只挖真相，金句频出。

## 2. 温情吃瓜 + 哲理
- 语言风格：共情能力强，从八卦引申出人生道理。
- 常用句："感情里哪有什么对错，只是有人提前退场。"
- 态度：温和但有立场，给读者情感共鸣。

## 3. 侦探式扒皮
- 语言风格：像写悬疑小说，罗列证据、时间线，引导读者自己推断。
- 常用句："注意这个时间点，三天后xx就…细思极恐。"
- 态度：客观中带引导，让读者欲罢不能。

## 4. 阴阳怪气 + 内涵
- 语言风格：表面客气实则句句藏刀，善用反问和"礼貌嘲讽"。
- 常用句："咱也不知道，咱也不敢问。""可能这就是'真性情'吧。"
- 态度：话里有话，让读者自己品出味道。

## 5. 理性分析 + 数据派
- 语言风格：用时间线、合同条款、商业逻辑剖析八卦。
- 常用句："按照时间线推算，这件事发生在合同到期前15天。"
- 态度：冷静克制，以理服人。
