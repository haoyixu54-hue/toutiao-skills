# 配图搜索与处理规范

## 搜索引擎策略（强制执行）

**百度为主，Bing 兜底。**

1. **首选 `BaiduImageCrawler`** — 百度图片对中文娱乐内容索引全面，微博截图、综艺画面、片场路透均能命中
2. **回退 `BingImageCrawler`** — 百度失败时才启用，作为补充
3. 禁止直接用 `requests` 抓取百度图片 HTML 页面（JS 动态渲染，正则匹配始终为空）
4. 每个图片搜索 `max_num=5`，取最大尺寸有效图片

## 搜索关键词规范

- 人名必须带身份区分词：`男演员`/`女演员`/`男歌手`/`女艺人` 防止同名混淆
- 反例：`白冰 偷税` → 可能返回女演员照片
- 正例：`网红白冰 男 探店 偷税` → 返回正确人物
- 事件截图类关键词需包含：时间（2026）、平台（微博/综艺名）、人物全名

## 水印模糊策略

- 检测图片底部 15% 区域：边缘密度 > 0.03 且亮度 > 120 → 判定为水印文字
- 判定为水印则高斯模糊半径 8px，仅模糊底部区域
- 不满足检测条件则跳过，避免误伤正常图片内容

## 图片嵌入规范

- .docx 中宽度 4.5 英寸，居中放置
- 无图片说明文字（蓝色占位符仅用于搜索失败时的标记）
- WebP 自动转 JPEG，质量控制 90
